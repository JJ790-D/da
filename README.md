# 答案之书 · The Book of Answers

一个神秘占卜风的「答案之书」网页：在心中默念（或输入）你的问题，点「翻开答案」后**占卜师会先问你两句**，再翻出「是 / 不是 / 也许…」的答案。**每位访客都能按自己喜好定制**，而且它会**根据你的满意/不满意反馈越用越懂你**。设置与记忆自动保存在各自的浏览器中，互不影响。

> 仅供娱乐，答案或许就在你心里。

## 文件结构

```
answer-book/
├── index.html   # 页面结构
├── style.css    # 视觉样式、主题、动画
├── script.js    # 随机答案、设置存储与交互
└── README.md    # 本说明
```

## 本地运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

或用本地服务器：

```bash
cd answer-book
python -m http.server 8000
```

访问 http://localhost:8000

## 可以定制什么

点右上角的 **⚙ 个性化设置**，即可调整：

- **主题风格**：神秘紫金、幽蓝海渊、玫瑰占卜、森之秘语、曜金圣殿 5 套主题
- **自定义强调色**：用取色器挑任意颜色，覆盖主题主色
- **专属文案**：主标题、副标题、封面文字
- **我的答案库**：添加 / 删除 / 点文字直接编辑答案，按肯定 / 否定 / 模糊分类筛选，一键恢复默认
- **体验开关**：揭晓音效、星空闪烁、问题输入框显示、**占卜师追问**、按反馈自适应开关
- **记忆与自适应**（核心）：见下方说明
- **备份与分享**：导出 / 导入 JSON 配置（含记忆），方便分享给朋友或换设备使用

所有设置保存在浏览器 `localStorage`，刷新页面依然保留；换浏览器或设备时用「导出/导入配置」迁移。

## 揭晓前的占卜师追问（趣味性）

点「翻开答案」后，不会立刻出结果——占卜师会先根据你的问题**挑一个场景**（感情、事业、财运、抉择、学业、身心，认不出就用通用问题），问你 2 道专属问题：

- 例如问「该不该表白」→ 进入「感情·心意」场景，追问"此刻你最真实的感受""更想要的是什么"
- 例如问「要不要跳槽」→ 进入「事业·前程」场景，追问"最打动你的是什么""结果不如预期会怎样"

**你的选择真的有用**：每个选项都带倾向——选「满怀期待」会让肯定类答案更容易出现，选「担心受伤害」则偏向否定，选「顺其自然」偏向模糊；选项里的关键词也会并入匹配。想直接看答案可点「直接翻牌」，或在设置里关掉「揭晓前占卜师追问」。这同样是纯前端规则，无需联网。

## 问题与答案如何匹配、如何不重复

这两个开关在设置的「体验开关」里，默认都开启：

- **按问题内容匹配答案**：每条答案带有「适用词」（设置里点答案右侧 ⚑ 可编辑，添加答案时也能填）。当你输入的问题命中适用词时，这条答案更容易被翻出；系统还会识别问句类别（如「怎么办」偏建议、「是不是」偏判断）做轻量匹配。此外你对某条答案点「满意」时，我会从你的问题里自动学几个关键词记到那条答案上，下次相似问题更容易翻到它。**这是纯前端的关键词/规则匹配，不是语义大模型**，但完全离线、隐私安全。
- **抽过的答案不再重复**：用滑动窗口记住最近翻出的答案，短期内不会重复；答案太少时自动放宽，保证总有可抽的。
- 两个开关可随时关闭，关闭匹配即恢复纯随机。

## 它如何越用越懂你

每次揭晓答案后，下方会出现「✓ 满意 / ✕ 不满意」：

- **单条答案权重**：满意的答案权重上调、更容易再出现；不满意的降温。权重被限制在合理区间（0.25 ~ 3.5），所以任何答案都不会彻底消失或一家独大。再点一次同一按钮可取消反馈。
- **类别偏好**：系统还会统计你对「肯定 / 否定 / 模糊」三类答案的满意率，用它微调这一整类出现的概率。反馈越多，调整越明显；样本不足时不会乱猜。
- **可查看 / 可关闭 / 可清除**：设置里的「记忆与自适应」能看到偏好分布和近期问答；关掉自适应开关就只记录不调整；「清除记忆」会重置所有权重与历史。
- 记忆仅存在你自己的浏览器里，不会上传，不同访客之间完全独立。

## 上传到 GitHub

1. 在 GitHub 新建一个仓库（例如 `answer-book`），可留空、不要勾选初始化 README。
2. 在本文件夹内执行：

```bash
cd answer-book
git init
git add .
git commit -m "Add customizable answer book web app"
git branch -M main
git remote add origin https://github.com/你的用户名/answer-book.git
git push -u origin main
```

3.（可选）开启 GitHub Pages：仓库 → Settings → Pages → Source 选 `main` 分支 / `root` → Save。
   之后可用 `https://你的用户名.github.io/answer-book/` 在线访问。

> 记得把 `你的用户名` 和仓库名换成你自己的。
